# 电机轴承保持架破损故障案例 PPT v2（WPS 放映版）

双兴分公司 BL-1655C 负压风机电机 2023-01-03 过流跳闸案例，班组学习分享用。20 页，16:9，正文约 26 分钟 + 讨论 3–5 分钟。

## 交付物（`out/`）

| 文件 | 说明 |
|---|---|
| `bearing_case_v2.pptx` | 成品（约 11 MB，视频已嵌入，每页有提纲式备注，标好了 `[点击]` 和用时） |
| `bearing_case_v2_preview.pdf` | 静态预览：每页显示动画**播完后**的样子（看不到动画本身） |
| `点击说明.md` | 一页“每页点几下”，由脚本按实际动画步骤生成 |
| `opening.mp4` | 开场 14 秒示意动画（1080p，无声），嵌入失败时备用 |
| `向双兴索要数据清单.pdf` | A4 一页，8 项数据 + 每项用途，可直接发给双兴；`.md` 是内部版，多一列“对应我方 PPT 页”，拿到数据后照着改 |

## 动起来的地方（全部用 WPS 也支持的普通动画，不依赖 Morph）

- 第 1 页：电机皮带轮、风机皮带轮、轴承内圈、滚珠组持续转动，电流表针轻微摆动（转动件是端视透明 PNG + 陀螺旋）。
- 第 2 页：嵌入视频，换页自动播放：正常运行 → 推近轴承 → 保持架断裂、滚珠扎堆 → 卡死 → 电流冲高 → 跳闸。第 1 页右侧画面与视频第一帧完全对齐，翻页时像镜头开始推进。
- 第 6 页：四步法每步配小动画：综保红灯闪烁；兆欧表针摆到“∞”；皮带拆走、皮带轮只晃不转；端盖滑开露出轴承室照片。
- 第 8 页：轴承转动（内圈快、滚珠组约 0.4 倍轴速）。
- 第 9 页：保持架碎成几段，8 颗滚珠沿滚道滑到一侧挤成一堆（逐颗路径动画）。
- 第 13 页：电流表针只动 1.2°（0.5 A），对比强烈。
- 第 14 页：六张嫌疑卡片从“平铺”飞到 1–4 名的排序位置。
- 第 17 页：圆点沿 P-F 曲线走到“功能失效”。
- 第 20 页：电机重新转起来，绿灯“恢复运行”，首尾呼应。

页面切换全部用“淡出”。原交接方案里的 Morph 改成了页内动画，因为 WPS 对 Morph 的支持需要实测，而且 WPS 在这里不靠 Morph 也能演。

## 放映前务必在 WPS 上从头放一遍

LibreOffice 只能检查静态版式，已确认所有动画 XML 都能被识别（闪烁、淡出退出、陀螺旋、路径、擦除、缩放、上浮）。下面几项必须在放映电脑上看：

1. 第 2 页视频是否自动播放；不播就单击画面。播完停在最后一帧（如果 WPS 播完退回第一帧，也不影响讲）。
2. 第 1、8、20 页的转动是否连续不卡。
3. 第 6 页的闪烁和指针，第 9、14、17 页路径动画的终点位置。

## 事实、推断、假设

- 原报告的事实没有改动；术语统一为“保持架”，第 2、8 页注明原报告写作“支持架”。
- 页面上用小标签区分 **【事实】【推断】【假设】【待双兴提供】**。计算页（第 12、13 页）的轴承型号 6312、85°C、粉尘系数、皮带轮 250 mm、300 W 摩擦损耗等都是为演示方法而设，已标【假设】。
- 没有编造停机时长、产量、加脂周期、运行时间。拿到双兴数据后，改 `build.js` 里对应文字重新生成即可。
- SKF 基准间隔约 6800 h 是二手资料的近似值，页面和备注都提示了“正式使用前请核对官方图表或 ABB 电机手册”。

## 重新生成

```bash
npm i                      # pptxgenjs react react-dom react-icons sharp；Playwright/Chromium、ffmpeg、LibreOffice 需已安装
./make.sh                  # 画 PNG 零件 → 渲染视频 → 生成 pptx → 注入动画 → 预览 PDF → 点击说明 → 数据清单
SKIP_RENDER=1 ./make.sh    # 只改了文字时用，跳过图片和视频渲染
```

| 文件 | 作用 |
|---|---|
| `render/scene.js` | 电机、皮带、轴承、表盘的画法（英寸坐标），PNG 零件和视频共用 |
| `render/render_assets.js` | 输出透明 PNG 零件到 `assets/gen/` |
| `render/opening.js`, `render/video.js` | 开场视频逐帧绘制，用 ffmpeg 编码 H.264 |
| `build.js` | 20 页版式、文字、备注；把动画步骤记到 `build/anim.json` |
| `anim.py` | 注入动画、切换、主题色、雅黑字体；`--final` 输出“动画播完后”的静态版，用于 PDF 预览 |
| `clickguide.py` | 生成点击说明，并检查备注里的 `[点击]` 次数和实际动画步骤一致 |
| `request_list.js` | 生成向双兴索要数据清单（PDF + 内部 md） |

原始材料在 `materials/`（原报告 PPT 和照片），交接说明见 `HANDOFF.md`。
