# 电机轴承保持架破损故障案例 PPT（最终版 · WPS 放映）

双兴分公司 BL-1655C 负压风机电机 2023-01-03 过流跳闸案例，班组学习分享用。20 页（第 1 页为公司原封面），16:9，正文约 24.5 分钟 + 讨论 3–5 分钟。面向现场应用，不含计算推导。

## 动起来的地方（全部用 WPS 也支持的普通动画，不依赖 Morph）

- 第 2 页：电机皮带轮、风机皮带轮、轴承内圈、滚珠组持续转动，电流表针轻微摆动（转动件是端视透明 PNG + 陀螺旋）。
- 第 3 页：嵌入视频，换页自动播放：正常运行 → 推近轴承 → 保持架断裂、滚珠扎堆 → 卡死 → 电流冲高 → 跳闸。第 2 页右侧画面与视频第一帧完全对齐，翻页时像镜头开始推进。
- 第 7 页：四步法每步配小动画：综保红灯闪烁；兆欧表针摆到“∞”；皮带拆走、皮带轮只晃不转；端盖滑开露出轴承室照片。
- 第 9 页：轴承转动（内圈快、滚珠组约 0.4 倍轴速）。
- 第 10 页：保持架碎成几段，8 颗滚珠沿滚道滑到一侧挤成一堆（逐颗路径动画）。
- 第 13 页：六张嫌疑卡片从“平铺”飞到 1–4 名的排序位置，左边留下“同类故障先查什么”。
- 第 14 页：机箱里的轴承一直在闪（在“生病”），巡检人沿路线走过：“看着都正常。”然后看、摸、听、电流逐个被划掉。
- 第 16 页：圆点沿 P-F 曲线走到“功能失效”。
- 第 17 页：现场检查要点。还是那台在转的电机，6 个检查点逐个闪出：轴承、加脂、皮带、散热筋、地脚、电流。
- 第 20 页：电机重新转起来，绿灯“恢复运行”，首尾呼应。

页面切换全部用“淡出”。原交接方案里的 Morph 改成了页内动画，因为 WPS 对 Morph 的支持需要实测，而且 WPS 在这里不靠 Morph 也能演。

## 放映前务必在 WPS 上从头放一遍

LibreOffice 只能检查静态版式，已确认所有动画 XML 都能被识别（闪烁、淡出退出、陀螺旋、路径、擦除、缩放、上浮）。下面几项必须在放映电脑上看：

1. 第 3 页视频是否自动播放；不播就单击画面。播完停在最后一帧（如果 WPS 播完退回第一帧，也不影响讲）。
2. 第 2、9、17、20 页的转动是否连续不卡。
3. 第 7、14、17 页的闪烁，第 10、13、14、16 页路径动画（滚珠、卡片、巡检人、圆点）的终点位置。

## 事实与推断

- 封面沿用公司原封面（形状、字体原样复制自 `materials/original.pptx`）。正文是独立的新 PPT，只用案例数据，不提原报告；术语用“保持架”，第 3、9 页注明“又称支持架”。
- 页面上用小标签区分 **【事实】【推断】**。
- 没有编造停机时长、产量、加脂周期、运行时间。拿到双兴数据后，改 `build.js` 里对应文字重新生成即可。
- 按使用意见去掉了计算页（润滑寿命、皮带拉力、电流灵敏度），只保留结论：高速 + 高温 + 粉尘要缩短加脂周期；皮带重点查对中和张力；电流反应太晚，早期靠冲击脉冲/测振。

## 重新生成

```bash
npm i                      # pptxgenjs react react-dom react-icons sharp；Playwright/Chromium、ffmpeg、LibreOffice 需已安装
./make.sh                  # 画 PNG 零件 → 渲染视频 → 生成 pptx → 注入动画 → 预览 PDF → 点击说明 → 数据清单 → 口袋卡
SKIP_RENDER=1 ./make.sh    # 只改了文字时用，跳过图片和视频渲染
```

| 文件 | 作用 |
|---|---|
| `render/scene.js` | 电机、皮带、轴承、表盘的画法（英寸坐标），PNG 零件和视频共用 |
| `render/render_assets.js` | 输出透明 PNG 零件到 `assets/gen/` |
| `render/opening.js`, `render/video.js` | 开场视频逐帧绘制，用 ffmpeg 编码 H.264 |
| `build.js` | 20 页版式、文字、备注；把动画步骤记到 `build/anim.json` |
| `anim.py` | 注入动画、切换、主题色、雅黑字体；`--final` 输出“动画播完后”的静态版，用于 PDF 预览 |
| `clickguide.py` | 生成点击说明，并检查备注里的 `[点击]` 次数和实际动画步骤一致 |
| `request_list.js` | 生成向双兴索要数据清单（PDF + 内部 md） |
| `handouts.js` | 生成巡检口袋卡和点击说明 PDF |

原始材料在 `materials/`（原报告 PPT 和照片），交接说明见 `HANDOFF.md`。
