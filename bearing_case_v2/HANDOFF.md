## 4. 分析内容（v2 的“深度”都在这里）

### 4.1 排查四步法【事实 + 方法提炼】
| 步骤 | 做法 | 结果 | 能排除什么 | 范围缩到 |
|---|---|---|---|---|
| ① 看保护 | 查综保动作记录 | 过电流动作 | 先列出可能：机械卡阻 / 缺相 / 绕组故障 | 整套设备 |
| ② 测绝缘 | 摇测绝缘电阻 | 合格 | 排除绕组接地、击穿 | 机械为主 |
| ③ 断负载 | 拆皮带，手动盘车 | 电机轴转不动 | 排除风机侧卡涩，也排除电源原因 | 电机内部 |
| ④ 解体查 | 拆电机 | 负荷侧保持架破损 | 找到实物证据 | 负荷侧轴承 |

口诀：**先查记录、再测电气、后拆机械；先外后内、先简后繁——每一步都缩小一次范围。** 关键一步是③：一下把范围从“整套设备”缩到“电机本身”。

### 4.2 保持架机理【事实/常识】
深沟球轴承由外圈（装在轴承室，不转）、内圈（随轴转）、滚珠、保持架组成。保持架的作用是把滚珠均匀隔开、带着它们有序滚动，相当于“隔离栏”；本例是薄钢板冲压件，相对单薄。保持架一断，故障就这样连锁发展：
1. 滚珠失去隔离，挤成一堆、互相摩擦卡住；
2. 转动阻力剧增，电机接近堵转；
3. 电流飙升，综保过流动作，停机。

**过流只是“结果”，保持架断裂只是“直接原因”。**

### 4.3 五个为什么【方法】
① 为什么停机？综保过流动作（保护是对的）→ ② 为什么过流？转子卡住 → ③ 为什么卡住？保持架破损、滚珠扎堆 →（**原报告到此为止**）→ ④ 为什么保持架会破损？**原报告没回答** → ⑤ 为什么跳闸前没发现？**管理原因，对我们最有借鉴意义**。

### 4.4 深挖① 证据：断口会说话
| 保持架/轴承上看到的 | 常见指向【常识，非本案结论】 |
|---|---|
| 兜孔磨大、变薄，有磨屑 | 润滑不良（缺脂、脂老化） |
| 铆钉断、两半分离 | 振动、冲击、频繁起停或加减速 |
| 兜孔横梁疲劳开裂 | 不对中、力矩载荷（偏载） |
| 钢件发蓝 / 发褐（回火色） | 曾经过热 |
| 滚道剥落、压痕、搓板纹 | 疲劳 / 安装冲击 / 电蚀（变频） |

- **本案能确认的【事实】**：保持架撕裂变形、滚珠扎堆、油脂发黑。
- **本案判断不了的**：属于哪种失效模式。照片没拍滚道、滚珠、轴颈，没有取油脂样，旧件是否留存不明。
- **可以讲成教训**：拆下来的东西就是证据，先拍、先留、先贴标签，再扔。

### 4.5 深挖② 算一算（每个数字都要在 PPT 上标【假设】）

**A. 润滑寿命：本案头号嫌疑**
- 【假设】负荷侧轴承为 6312（机座号 200 常见规格，d=60、D=130 mm；型号以实物为准）。
- 速度因子 n·dm = 2950 × (60+130)/2 = 2950 × 95 ≈ **28 万**。
- 按 SKF 加脂间隔方法（深沟球轴承、70°C 基准）：基准间隔 t_f ≈ **6000–7000 h**。这是二手资料给出的近似值；正式使用前请用 SKF 官方图表/计算器，或 ABB 电机手册里机座号 200 的润滑表核对。
- 温度修正：比 70°C 每高 15°C，间隔减半（85°C ×0.5，100°C ×0.25）。
- 污染修正：轻度 ×0.5–0.7，重度 ×0.2–0.4。
- 【假设】情景：轴承 85°C、中重度粉尘 ×0.3–0.5 → 6800 × 0.5 × (0.3–0.5) ≈ **1000–1700 h ≈ 1.5–2.5 个月**（24 h 连续运行）；若到 100°C 则只剩约 **3–5 周**。
- 【推断】结论：如果双兴的加脂周期按半年甚至没有固定周期，轴承可能有几个月处在缺油状态。这与“油脂发黑 + 2 极高速 + 封闭积灰”相吻合。
- 如果是免维护密封轴承（2Z/2RS），结论类似：密封脂寿命同样随温度每升 15°C 减半。

**B. 皮带拉力：没想象中可疑**
- 转矩 T = 9550 × P / n = 9550 × 30 / 2950 ≈ **97 N·m**。
- 【假设】电机皮带轮直径 250 mm（照片估计，需实测）→ 有效拉力 F_e = 2T/d ≈ **780 N**。三角带作用在轴上的力约为 (1.5–2.5)×F_e，即 **1–2 kN**。
- 【假设】6312 额定动载荷 C ≈ 85 kN。L10 = (C/P)³ × 10⁶ 转：P=2 kN 时寿命以几十万小时计；即便严重过紧到 P=5 kN，L10 ≈ 2.8 万 h（约 3 年连续运行）。
- 【推断】结论：正常张紧下，“压坏”轴承的不是皮带的径向力本身；皮带的真正危害是**不对中、抖动和额外发热**。嫌疑排序应调整为：**润滑/温度 > 皮带对中/振动**。

**C. 电流为什么发现不了早期轴承故障**
- 【假设】轴承劣化后多出 300 W 摩擦损耗 → ΔI = 300 / (√3 × 380 × 0.91) ≈ **0.5 A**，不到额定 54.8 A 的 **1%**，淹没在负载波动里。
- 结论：电流是“最晚”的信号，等它明显上升时已接近卡死；早期只能靠**冲击脉冲 / 测振**。（v1 写的“结合综保电流一起看”要改：电流只能作后期佐证。）

### 4.6 嫌疑排序（更新版，替代 v1 的“六个嫌疑方向”平铺）
1. **润滑失效 + 温度高**：油脂发黑、散热筋积灰、封闭机箱；计算显示加脂间隔可能只有 1–2 个月 → 头号嫌疑【推断】
2. **皮带不对中 / 振动**：坏在负荷侧；需核实张力、对中、地脚【推断】
3. **2 极高转速**：本身不是“原因”，而是“放大器”，让 1、2 的影响更快显现【推断】
4. **轴承寿命 / 安装质量**：缺数据，待核实

### 4.7 深挖③ 为什么跳闸前没人发现：监测盲区
- 【推断】这台电机在封闭机箱里，负压风机噪声大 → **看不见、摸不到、听不清**；它很可能不在冲击脉冲/测振路线上；电流对早期故障不敏感。
- 结论：这是一台“**监测盲区设备**”，巡检再认真也发现不了。原报告“加强巡检”解决不了盲区问题。
- 对策：
  - 把盲区设备单列出来；
  - 测点引到机箱外、注油管加长到机箱外；
  - 纳入冲击脉冲路线；
  - 必要时加在线温度/振动传感器；
  - 针对这类设备缩短加脂周期。

### 4.8 劣化四阶段（P-F 曲线示意，非实测数据）
| 阶段 | 现象 | 怎么发现 |
|---|---|---|
| 一 早期微损 | 看不出、听不到、温度正常 | 冲击脉冲、超声 |
| 二 劣化发展 | 振动渐增、油脂变质 | 测振、冲击脉冲趋势、看油脂 |
| 三 明显异常 | 异响、轴承发烫 | 听音棒、测温枪（电流此时仍不明显） |
| 四 功能失效 | 卡死、冒烟、跳闸 | 保护动作——已经晚了 |

本案在阶段四才发现；目标是在阶段一、二发现。主讲人班组正在做的“转动设备滚动轴承冲击脉冲档案表（HDm/HDc）”就是阶段一、二的工具，关键是**连成趋势**。

### 4.9 维修做法点评
- **做对的**：两侧轴承一起换；复测绝缘再送电；接线试机验证。
- **建议补充**：
  1. 检查轴颈、轴承室磨损，防“跑圈”；
  2. 清净旧脂，按规定型号和量加新脂，高速电机不能加满；
  3. 核对轴承型号和游隙（如 C3），加热安装，不锤击；
  4. 检查皮带张力和对中；
  5. 清理散热筋和机箱积灰；
  6. 试机后记录电流、温度、冲击脉冲，留作日后对比的“基准值”。

## 5. 举一反三 2.0（v2 重做，替代 v1 的四张卡片）

分三层讲，每条都要落到“谁、查什么、交什么”：

**设备层：横向排查同类设备**
1. **筛同类**：2 极（≥2900 r/min）+ 皮带传动 + 封闭/粉尘/高温环境，三条中占两条即列入。产出《重点电机清单》，字段：位号、功率、转速、传动方式、环境、轴承型号、能否加脂、上次加脂、监测方式、最近一次冲击脉冲值。
2. **推到其他转动设备**：泵、风机、空压机的滚动轴承同理，“高速 + 高温 + 污染 = 润滑寿命成倍缩短”。
3. **改设计（向上反馈）**：评估 2 极电机配皮带传动是否合理（直连、改 4 极、调整皮带轮），机箱通风散热，皮带张紧标准化（用张力计）。

**管理层：把“加强”变成“具体动作”**

4. **找盲区**：判定标准是近不了身、听不清、摸不到、不在测点路线上。对策见 4.7。
5. **润滑周期按工况修正**：不一刀切，用转速、温度、污染修正周期，写进加脂台账（哪台、什么脂、加多少、多久、谁加）。
6. **监测选对指标**：冲击脉冲/振动是早期信号，温度/听音是中期，电流是晚期（<1%）。每台建立基准值、趋势和报警线，把冲击脉冲档案表真正用起来。

**方法层：以后我们自己怎么做**

7. **证据保全清单**：拆检必拍滚道、滚珠、保持架断口、油脂、轴颈、轴承室、密封；旧件封存贴标签；必要时取油脂样。
8. **故障报告写深**：用第 7 节第 18 页的模板，至少回答“为什么坏”和“为什么没提前发现”。

## 6. 讲法主线（故事线）

把主线从“讲一个故障”升级为“**一份浅报告，怎么挖深**”：

1. **钩子（2 min）**：电机动画，正常运转 → 保持架断 → 卡死 → 电流冲红 → 跳闸。
2. **回顾（4 min）**：设备、时间线、排查四步法（第一个干货）。
3. **反转（2 min）**：五个为什么，“原报告只答到第三个”。
4. **深挖（10 min）**：证据 → 算一算 → 嫌疑排序 → 监测盲区。
5. **落地（6 min）**：P-F 四阶段 → 举一反三 2.0 → 深报告模板。
6. **收尾（3–5 min）**：三句话 + 讨论。

## 8. 电机动画方案（炫技重点）

**推荐组合：开场用视频 + 其余用 PPT 原生动画。** 先问用户放映电脑的 Office 版本（见第 13 节）。

### 方案 A：PPT 原生动画（可编辑，兼容好）
- **转动件用“端面视图”做成独立透明 PNG**，再加 Spin（Spin 只绕图形中心转，所以侧视剖面图上的转子转了也看不出）。可以：电机侧视剖面做静态底图，叠加几个圆形“端面小窗”（风扇、皮带轮、轴承滚珠组），让它们转。
- **轴承滚珠绕圈**：把滚珠 + 保持架画成一张透明 PNG 单独转。外圈静止；内圈随轴转；滚珠组（保持架）公转速度约为轴速的 0.4 倍，示意时让滚珠组转得比内圈慢即可。
- **让转动“停下来”**：Spin 设成无限循环会一直转到换页；要停，就点击时让旋转图淡出，同位置淡入一张静止图，或者 Morph 到下一页。
- **电流表指针**：指针图做成正方形透明画布，指针从中心画到边缘，这样旋转中心就是表盘中心；用 Spin 部分角度（如 90°）甩到红区。
- **报警灯闪烁 / 盘车卡住抖动**：用“闪烁 / 跷跷板”等强调效果。最可靠的做法是在 PowerPoint 里手做一个，另存后读出 XML 当模板（preset ID 我没有逐一实测，不要凭记忆写）。
- **Morph（平滑）**：两页中要对应的对象用相同的 objectName，并以 `!!` 开头（如 `!!b0`…`!!b8`）。
- **路径动画**：P-F 曲线上的小圆点沿曲线移动。

### 方案 B：嵌入 MP4 视频（最炫，兼容也好）
- 用代码渲染 10–20 s、1080p、H.264 的短片（无声或静音），比如：电机剖面 → 轴承放大 → 保持架断裂、滚珠扎堆 → 转速归零 → 电流冲红 → 跳闸。
- 可选工具：Blender（Python 脚本建模渲染）、three.js + Playwright 录屏 + ffmpeg、或 2D 的 manim / matplotlib。
- 用 python-pptx 的 `add_movie` 嵌入（不要链接外部文件），设置封面帧和自动播放。
- 视频里**不要出现**能被误认为真实监控画面的东西，就是示意动画。

### 方案 C：3D 模型（.glb）+ Morph
- 只有 PowerPoint 365/2019 支持，WPS 不支持。**除非用户确认放映环境是 365，否则不做。**

## 9. 视觉规范（沿用 v1，可升级）

- **配色**（主题色写在 theme 里，见 `build.js` 的 THEME）：深海军蓝 `0E2240`（暗页/标题）、品牌蓝 `1D5FAE`、警示橙 `E8772E`（故障/重点）、红 `D64541`（失效/危险）、绿 `2E9E6B`（正常/目标）、灰 `5B6B7C`、浅底 `F2F5F9`。
- **字体**：微软雅黑（Microsoft YaHei）。theme 的 `ea` 字体和 `Hans` 脚本字体必须改成雅黑，否则中文会落到“等线”。
- **标点**：中文用全角引号 “ ”，不要用半角 `"`。
- **Logo**：浅色页用透明底彩色 logo，暗色页用反白 logo（都在 `assets/`）；原图分辨率低，不要放大超过约 3 英寸宽。
- **母题**：轴承圆环（外圈 + 橙色保持架 + 滚珠）贯穿封面、知识页、结尾。
- **避免**：标题下划线、装饰色条、整页只有文字、正文小于 12 pt。

## 10. 技术要点 / v1 踩过的坑

1. **pptxgenjs 没有动画 API**：v1 的做法是每个形状设 `objectName`，在 `build.js` 里把动画步骤记到 `anim.json`，再由 `anim.py` 按名字找 `spid`，注入 `<p:timing>`。
2. **`anim.py` 已支持并验证的效果**：
   - 进入：fade、float（上浮）、wipeL（从左擦除）、zoom；
   - 强调：spin（可设角度 `deg`、`repeat: "indefinite"`）；
   - 路径：path（`"M 0 0 L 0.1 0.05 E"`，单位为幻灯片宽高的比例）；
   - 切换：淡出、Morph（带淡出回退）。
   - 都已通过 OOXML 校验，LibreOffice 导入时能识别为对应预设。
3. **时序规则**：每页只有第一步可以是“自动”，其余每步一次点击；cTn id 全页唯一；同一形状有多个动画时 grpId 递增（0、1…），bldLst 里每个 (spid, grpId) 一条。
4. **Morph 的 XML**：`mc:AlternateContent`，Choice 里是 `p159:morph`，Fallback 里是 `p:fade`，放在 `</p:clrMapOvr>` 之后、`<p:timing>` 之前。
5. **图标**：react-icons → SVG → sharp 转 PNG。替换 SVG 宽高时注意正则不要误伤 `stroke-width`（v1 踩过，图标被裁）。
6. **QA**：LibreOffice 渲染只能检查静态版式（溢出、重叠），看不到 Morph、视频和多数动画效果。**最终必须在用户的放映电脑上用实际版本的 PowerPoint/WPS 从头放一遍。** 另外，把 pptx 转成 odp 后检查 `presentation:preset-id`，可以确认动画 XML 能被解析。
7. 不要把文字烤进图片：除电机插画/视频外，所有文字都必须能在 PowerPoint 里直接改。

## 11. 硬性约束

- 第 3 节的事实不得改动；缺的数据用 `【待双兴提供】` 占位，**不得编造**停机时长、产量、加脂周期、运行时间等。
- 所有推断和假设在页面上用小角标标出（【推断】/【假设】），备注里说明依据。

- 每页都有备注（提纲式、[点击] 标记、用时）。
- 16:9；文件 ≤ 50 MB；字体雅黑；保留公司 logo。

## 13. 开工前先问用户的问题

1. 放映电脑用什么软件：PowerPoint 365 / 2019 / 2016，还是 WPS？（决定能不能用 Morph、视频、3D）
2. 分享时长有没有限制？20 分钟就要砍到 14–15 页。
3. 公司电脑能不能播放嵌入视频（有的内网电脑缺解码器）？
4. 能不能从双兴拿到第 14 节的数据？拿到的话，【假设】可以换成实测。

## 14. 向双兴索要的数据（拿到一项就能把一处“推断”变成“实证”）

1. 轴承型号（DE / NDE），有没有油嘴（开式还是密封式）
2. 这套轴承运行了多久，上次加脂和更换时间，规定的加脂周期和加脂量
3. 拆下的旧轴承在不在：滚道、滚珠、保持架断口的照片或实物
4. 故障前的巡检记录（温度、声音），这台在不在冲击脉冲/测振路线上，历史数值
5. 跳闸前的电流记录（综保或 DCS）
6. 皮带张力、皮带轮对中检查结果，皮带轮直径
7. 停机时长、产量影响
8. 同型号、同工况电机的故障史
