# 行测刷题工具包 · 从这里开始

> 配合免费开源题库 **xingcezhenti**（GitHub：ERRRC/xingcezhenti）使用。题目、答案和解析都在题库里，本工具包负责帮你**找卷、排计划、记错题、看考情**。

## 三步开始

1. 在下面「按考试找卷」点你要考的地区，看看有哪些卷
2. 打开同一地区的「30 天计划」，每天照着刷，刷完打勾
3. 做错的题记进[[00-刷题工具包/03-错题本/错题本|错题本]]，复盘日重做

## 说明

- 题库是 GitHub 上的免费开源项目，题目、答案、解析的版权归原作者和原出处，本工具包不包含任何题目内容。
- 工具包里的链接指向题库里的文件，所以要把「00-刷题工具包」文件夹放进题库文件夹里才能用（见使用教程）。
- 打勾的进度保存在你自己的文件里，换电脑时整个文件夹一起拷走即可。
