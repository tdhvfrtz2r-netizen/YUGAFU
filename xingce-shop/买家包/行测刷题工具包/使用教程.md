# 行测刷题工具包 · 使用教程

**10 分钟搞定，跟着做就行。**

你买到的是一套「刷题工具包」：按考试找卷的目录、35 份 30 天刷题计划、错题本、十年考情速览，外加答疑。

题目本身来自 GitHub 上一个**免费开源**的题库项目 **xingcezhenti**（作者 ERRRC），收录 2016–2026 年 515 套行测卷，有答案和解析。下面教你把题库拿到手、和工具包装在一起。

---

## 第一步：下载题库（约 260 MB）

**推荐用电脑**，手机也可以（见文末）。

用电脑浏览器（Chrome、Edge 都行，**不要在微信里直接打开**）打开下面这个链接，会直接开始下载：

**https://github.com/ERRRC/xingcezhenti/archive/refs/heads/main.zip**

等它下完，你会得到一个 `xingcezhenti-main.zip`。

> 链接点了没反应？那就打开项目主页 **https://github.com/ERRRC/xingcezhenti** ，点绿色的 **「<> Code」** 按钮，再点菜单最下面的 **「Download ZIP」**。

**下不动 / 打不开怎么办？**

- GitHub 在国内能打开，就是有时候慢。换个时间（早上、深夜一般快）或换网络（试试手机热点）再点一次
- 下载中断了就重新点 Download ZIP
- 还是不行，直接找卖家，我们帮你想办法

## 第二步：解压

- **Windows**：右键 zip →「全部解压缩」。文件有 4 万多个，系统自带的解压比较慢，装个 Bandizip 或 7-Zip 会快很多
- **Mac**：双击 zip 自动解压

解压后得到一个 `xingcezhenti-main` 文件夹，里面能看到 `01-政治理论`、`02-常识判断`……`90-图片` 这些文件夹，说明对了。

> 如果解压后外面又套了一层同名文件夹，就进到里面那一层，以能看到 `01-政治理论` 的那一层为准。

## 第三步：放入工具包

把工具包里的 **`00-刷题工具包`** 整个文件夹，复制到上一步那个能看到 `01-政治理论` 的文件夹里。

放好后应该是这样：

```
xingcezhenti-main
├── 00-刷题工具包      ← 你放进来的
├── 01-政治理论
├── 02-常识判断
├── ……
├── 06-资料分析
└── 90-图片
```

## 第四步：用 Obsidian 打开

Obsidian 是一个免费的笔记软件，用它看题最方便：图片、链接、打勾都能用。

1. 去官网 **obsidian.md** 下载安装（免费，有中文）
2. 打开后选 **「打开本地仓库」**（英文界面叫 *Open folder as vault*）
3. 选中 `xingcezhenti-main` 这个文件夹
4. 第一次打开要建索引，等几十秒
5. 在左边文件列表里点开 **`00-刷题工具包` → `00-从这里开始`**

到这里就全部装好了。

## 怎么刷

- **找卷**：首页点你要考的地区，比如「浙江」，就能看到浙江 2016–2026 年所有卷，每个模块一个链接，点进去就是题目、答案和解析
- **按计划刷**：首页点同一地区的「30 天计划」，每天做 2 组专项，最后 6 天整卷模考
- **打勾**：每个方框直接点一下就勾上了，进度自动保存
- **记错题**：错的题记进「错题本」，第 7、14、21 天复盘日重做

> 小提示：题目页面里答案就在选项下面。想先做再看答案的话，准备一张白纸写答案，做完一组再往下翻。

## 用手机怎么弄

能用电脑的话，优先用电脑。手机也能用，就是解压 4 万多个文件比较慢。

**iPhone**

1. 用 Safari 打开第一步的下载链接，下载完在「文件」App 里找到 zip，点一下就会自动解压
2. 应用商店装 Obsidian，打开后随便新建一个仓库，「文件」App 的「我的 iPhone」里就会出现 `Obsidian` 文件夹
3. 把解压出来的题库文件夹和工具包都移进 `Obsidian` 文件夹（工具包要放在题库文件夹里面）
4. 打开 Obsidian，选这个文件夹

**安卓**

1. 用浏览器下载 ZIP，用文件管理器（或 ZArchiver）解压
2. 把 `00-刷题工具包` 放进解压后的文件夹
3. 安装 Obsidian →「打开本地仓库」→ 选这个文件夹

## 常见问题

**图片不显示？** 确认你打开的是整个 `xingcezhenti-main` 文件夹，而不是单独点开一个文件；也确认 `90-图片` 文件夹在里面。

**点链接提示「文件不存在」？** 说明 `00-刷题工具包` 没放对位置，它必须和 `01-政治理论` 在同一层。

**不想装 Obsidian 行不行？** 题目文件是普通的 Markdown，用 Typora、VS Code 也能看题，但工具包里的跳转链接和打勾只有 Obsidian 能用。

**题目有缺图？** 题库是网友回忆版，个别题少图，原项目里有一份「图片缺失清单」。

**有问题找谁？** 直接在下单的平台私信卖家。
