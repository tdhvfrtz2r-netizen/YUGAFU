# 卖家手册

## 文件在哪

| 文件 | 干什么用 |
|---|---|
| `行测刷题工具包_v1.zip` | **发给买家的就是这个**（584 KB，内含工具包 + 使用教程.pdf，不含题目） |
| `买家包/行测刷题工具包/` | 上面 zip 解压后的样子，自己先装一遍试试 |
| `上架素材/闲鱼`、`小红书`、`抖音` | 配图，序号就是上图顺序 |
| `上架文案.md` | 三个平台的标题、描述、正文、快捷回复、视频脚本 |
| `工具/` | 重新生成工具包的脚本（题库更新时用，见下文） |

## 上架前先自己走一遍

1. 按 `使用教程.pdf` 自己从 GitHub 下题库、装 Obsidian、放入工具包
2. 点开「00-从这里开始」，随便点几个地区、几份计划，确认链接都能跳、图片能显示
3. 顺手录一段屏，抖音视频和小红书都能用

自己装过一遍，回答买家问题才有底。

## 发货

1. 把 `行测刷题工具包_v1.zip` 传到网盘（百度网盘 / 夸克 / 阿里云盘都行），生成分享链接
2. 闲鱼发布时选「虚拟商品 · 自动发货」，发货内容填：

```
感谢购买！工具包链接：（网盘链接） 提取码：（提取码）

先打开里面的「使用教程.pdf」，跟着做就能装好：
① GitHub 下载免费题库 → ② 解压 → ③ 把「00-刷题工具包」放进题库文件夹 → ④ 用 Obsidian 打开

卡在哪一步，直接截图发我。
```

## 售后

- **下载不动**：让买家换浏览器（别用微信内置）、换网络（手机热点）、换时间段。还不行，就用远程桌面或截图一步步带他操作，**别把题库文件发过去**
- **链接点了没反应 / 提示文件不存在**：多半是 `00-刷题工具包` 没放对层级，它必须和 `01-政治理论` 在同一个文件夹里
- **图片不显示**：买家只打开了单个文件，没用 Obsidian「打开本地仓库」打开整个文件夹
- **实在装不好**：直接退款。9.9 的单子不值得吵，一个差评的损失比这大得多

## 题库更新了怎么办

原项目的题库是脚本生成的，作者可能会更新（比如加 2027 年的卷）。文件名一变，工具包里的链接就会失效。更新步骤：

```bash
git clone --depth 1 https://github.com/ERRRC/xingcezhenti
python3 工具/parse.py xingcezhenti data.json
python3 工具/build_kit.py data.json 输出目录
```

跑完把 `输出目录/00-刷题工具包` 和使用教程.pdf 重新打包，版本号改成 v2，网盘链接一并更新。不会弄就把新题库发给我，我帮你重新生成。

## 风险，提前想好

- **原项目被删或改成私有**：买家就下不到题库了，工具包也就没用了。这种情况马上下架所有商品，最近买的人主动退款
- **题库本身的版权**：解析来自题库原出处，原项目作者没有写开源许可证。所以你只发工具包和教程，不发题目；文案里不说「独家」「自己整理的真题」
- **平台规则**：闲鱼、小红书、抖音对虚拟资料类商品都在收紧，规则以平台后台为准。被平台判违规了就按要求改，别跟平台硬刚
