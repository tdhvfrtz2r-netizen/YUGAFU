# 卖家手册 · 刷题 App 版

## 卖的东西

1. **刷题 App**（主打）：一个网页 App，手机浏览器打开链接就能用，可以添加到桌面。515 套真题，能练习、背题、限时模考自动打分，错题自动收集，带 30 天计划和十年考情速览
2. **PDF 打印版**（赠送）：每套卷一个 PDF，答案在最后一页

两样都**不含解析**，只有题目和答案。

## 文件在哪

| 文件 | 干什么用 |
|---|---|
| `刷题App.zip` | **App 的全部文件**（约 220 MB）。上线（见下文）之后，买家拿到的是一个链接 |
| `行测真题2016-2026（手机版）-第1部分.zip`、`第2部分.zip` | PDF 打印版，传网盘发给买家 |
| `上架素材/` | 配图，按平台分好了 |
| `上架文案.md` | 标题、描述、快捷回复、视频脚本 |
| `app/` | App 的源代码（不含题目） |
| `工具/` | 重新生成题库数据和 PDF 的脚本 |

带题目的文件（App 数据和 PDF）只在聊天里直接发给你，没有放进 GitHub 仓库，因为仓库是公开的。

## 第一步：把 App 放到网上（必须做）

App 是网页，要放到一个网址上，买家才能用手机打开。三个办法，按稳定程度排：

| 办法 | 要多久 | 花多少钱 | 国内手机打开 |
|---|---|---|---|
| **A. 腾讯云 / 阿里云「对象存储」开静态网站，绑自己的域名** | 域名要备案，一般 1–3 周 | 域名一年几十元，存储和流量很便宜（几十个买家一个月几块钱） | 稳定，微信里也比较少被拦 |
| **B. 国内云的默认测试域名** | 当天 | 很便宜 | 能打开，但测试域名有限制，可能被提示风险，只适合先试 |
| **C. Cloudflare Pages / Netlify 免费托管** | 半小时 | 免费 | 不稳定，有时很慢或打不开，微信里经常被拦 |

**建议**：先用 C 或 B 当天上线，自己和几个朋友试用；同时去办域名备案，备案下来后换成 A，长期用。

上传的东西就是 `刷题App.zip` 解压出来的整个文件夹（里面有 `index.html`、`app.js`、`data/`、`img/` 等），网站的首页文件设成 `index.html`。具体操作我可以一步步带你做，你选好用哪家告诉我。

**注意**：
- 拿到链接的人谁都能用。链接只发给买家，别发在笔记、评论、视频里
- 发现链接被到处转，可以把文件挪到一个新的文件夹地址，旧链接就失效了，再给老买家发新链接
- 必须用 https 的网址，App 才能离线缓存和添加到桌面

## 第二步：PDF 打印版传网盘

1. 把两个 PDF 压缩包解压到同一个地方，会合成一个 `行测真题2016-2026（手机版）` 文件夹
2. 整个文件夹传到网盘（百度网盘 / 夸克 / 阿里云盘），分享文件夹链接
   - 只有手机的话：先把压缩包传到网盘，再用网盘自带的「在线解压」（部分网盘要会员）


## 上架前先自己用一遍

1. App 上线后，用自己手机打开：选地区 → 开始 30 天计划 → 做几道练习 → 做一次模考交卷看成绩 → 看错题本
2. iPhone 和安卓各试一下「添加到桌面」
3. 在微信里点一下链接，看会不会被拦（被拦就在发货话术里提醒买家用浏览器打开）
4. 顺手录屏，抖音和小红书都能用

## 售后

- **打不开**：让买家复制链接到手机浏览器打开，别在微信里打开
- **记录没了**：记录存在买家自己的浏览器里，换手机、清理浏览器、无痕模式都会丢，这个在描述里写了
- **问有没有解析**：如实说没有，教他长按复制题干去搜
- **说某题缺图**：网友回忆版本来就有少量缺图，描述里写了；态度好一点，必要时退款
- **要求退款**：9.9 的单子不值得吵，一个差评的损失比这大得多

## 原题库更新了怎么办

原项目以后可能会加新的卷（比如 2027 年的）。把新题库链接发给我，我重新生成 App 数据和 PDF；或者自己跑 `工具/` 里的脚本（要装 Node、Playwright 和字体）。

## 风险，心里有数

- **解析不放**：解析是培训机构写的原创内容，这是最容易被投诉的部分，所以 App 和 PDF 里都没有
- **题目文本**：回忆版真题是全行业都在卖的东西，但这份题目是从某家题库整理出来的，人家真投诉的话，平台会下架商品、托管商可能关掉网站。被下架就按要求处理，别硬刚
- **平台规则**：闲鱼、小红书、抖音对虚拟资料类商品都在收紧，规则以平台后台为准
- **文案别夸大**：不写"官方""含解析""独家"，描述和实物一致，差评和投诉就少
