# 卖家手册 · 手机版真题包

## 文件在哪

| 文件 | 干什么用 |
|---|---|
| `行测真题2016-2026（手机版）.zip` | **要发给买家的真题包**（约 630 MB）。这个文件只在聊天里直接发给你，没有放进 GitHub 仓库，因为仓库是公开的 |
| `上架素材/闲鱼`、`小红书`、`抖音` | 配图，序号就是上图顺序 |
| `上架文案.md` | 三个平台的标题、描述、正文、快捷回复、视频脚本 |
| `手机版/使用说明.md` | 包里「使用说明.pdf」的源文件，想改字就改这里 |
| `工具/` | 重新生成真题包的脚本（原题库更新时用） |

## 真题包里有什么

```
行测真题2016-2026（手机版）
├── 00 先看我：使用说明.pdf
├── 00 十年考情速览.pdf
├── 00 30天刷题计划/      35 份，每个地区一份
├── 01 国考/              27 套
├── 02 北京/ …… 35 选调/  每套卷一个 PDF
```

- 515 套卷，每套一个 PDF，手机竖屏大小，题目在前、答案在最后一页
- **不含解析**（解析是培训机构写的，不放）
- 已经检查过：515 套的题数全部对得上原始数据，没有任何一份漏出答案标记或解析

## 上架前先自己看一遍

1. 把 zip 解压，在手机上随便点开几套卷：国考、你自己的省、一套带资料分析图表的
2. 翻到最后一页核对一下答案
3. 打开一份 30 天计划，按它写的题号找一下，确认能对上
4. 顺手录一段屏，抖音和小红书都能用

## 发货

**推荐做法：网盘里放解压好的文件夹，分享文件夹链接。** 买家在网盘 App 里直接点开 PDF 就能看，手机上不用解压。

1. 在电脑上解压 zip，把整个 `行测真题2016-2026（手机版）` 文件夹上传到网盘（百度网盘 / 夸克 / 阿里云盘都行）
   - 只有手机的话：先把 zip 传到网盘，再用网盘自带的「在线解压」解压出文件夹（部分网盘要会员）
2. 分享这个文件夹，生成链接
3. 闲鱼发布时选「虚拟商品 · 自动发货」，发货内容填：

```
感谢购买！真题包链接：（网盘链接） 提取码：（提取码）

在网盘 App 里直接点开 PDF 就能看，不用解压、不用装软件。
建议先看「00 先看我：使用说明」，再打开「00 30天刷题计划」里你要考的地区，照着每天刷。

有打不开的直接私信我。
```

## 售后

- **打不开 / 看不了**：让买家在网盘 App 里直接点 PDF；或者保存到手机后用 WPS 打开
- **问有没有解析**：如实说没有，教他把题干复制去搜
- **说某题缺图**：网友回忆版本来就有少量缺图，描述里写了；态度好一点，必要时退款
- **要求退款**：9.9 的单子不值得吵，一个差评的损失比这大得多

## 原题库更新了怎么办

原项目以后可能会加新的卷（比如 2027 年的）。更新步骤：

```bash
git clone --depth 1 https://github.com/ERRRC/xingcezhenti
python3 工具/parse.py xingcezhenti data.json
python3 工具/build_kit.py data.json kit plans.json
node 工具/build_pdfs.js xingcezhenti 输出目录 字体目录 pdf_index.json
node 工具/docs_pdf.js 手机版/使用说明.md kit/00-刷题工具包/04-十年考情速览.md plans.json pdf_index.json 输出目录 字体目录
```

脚本要装 Node、Playwright 和字体，不会弄就把新题库链接发给我，我帮你重新生成。

## 风险，心里有数

- **解析不放**：解析是培训机构写的原创内容，这是最容易被投诉的部分，所以真题包里没有
- **题目文本**：回忆版真题是全行业都在卖的东西，但这份题目是从某家题库整理出来的，人家真投诉的话，平台会下架商品。被下架就按平台要求处理，别硬刚
- **平台规则**：闲鱼、小红书、抖音对虚拟资料类商品都在收紧，规则以平台后台为准
- **文案别夸大**：不写"官方""含解析""独家"，描述和实物一致，差评和投诉就少
