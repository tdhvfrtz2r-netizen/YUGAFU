## 二、一排工资条（0:20–0:55）

**要讲明白**：你最大的资产是未来几十年的工资；它会一年年用完，也可能被提前切断。存钱，是把其中一部分换成不会被切断的东西。

| 口播 | 动画（逐步） |
|---|---|
| 先看一张图。 | 25 岁的小人站在左边 |
| 二十五岁的你，身后是一排工资：每一格，是一年的收入。 | 小人右侧依次亮起 35 个金色方块，一直排到 60 岁，每格标"12 万" |
| 这排工资，是大多数人最大的资产。 | 方块上方出现大括号："你的身价 ≈ 未来所有工资" |
| 但它有两个问题：一是会一格一格用完， | 时间指针向右走，走过的方块逐个变暗 |
| 二是可能被提前切断。 | 指针走到 45 岁，一道红色裁员线"咔"地切下，后面的方块碎裂、变灰 |
| 小林的做法，是每年从这一格里，切下三成，存进一个不会被裁员的账户。 | 画面回到 25 岁，换成小林的那一排。每格切下 30%（金色小块），落进下方的保险箱，保险箱越来越亮 |
| 阿杰的做法，是用分期，把后面几格的工资，提前花掉。 | 阿杰的那一排：后面的方块被提前盖上红章"已预支"，红章越盖越多 |

## 三、阿杰的水池（0:55–1:30）

**要讲明白**：问题不在阿杰花了多少，而在于他有多少"收入停了也停不下来"的支出。

| 口播 | 动画 |
|---|---|
| 把阿杰每个月的钱，画成一个水池。 | 一个透明水池，上方一个进水龙头 |
| 进水，是一万块工资；出水，是房贷、车贷、各种分期。 | 进水口标"+¥10,000"；底部三根出水管依次接上："房贷 ¥5,200""车贷 ¥2,300""分期 ¥1,500" |
| 平时，水池刚好够用，看不出问题。 | 水位在低处来回波动，始终没干 |
| 这些出水管有个特点：收入停了，它们不会停。 | 出水管上出现锁的图标 |
| 被裁那天，进水一关，水池不到一个月就见底。 | 龙头"咔"地关闭；出水管照常流；水位快速下降，右上角倒计时从 30 天跳到 0，水池见底变红 |
| 难的不只是没钱，更是每个月必须付出去的钱。 | 三根带锁的管子特写 |

## 四、小林的雪球（1:30–2:20）

**要讲明白**：①复利为什么前慢后快；②真正的难点是暴跌时不卖。

| 口播 | 动画 |
|---|---|
| 小林这边，每年存三万六。 | 柱状图，每年一根柱子，灰色部分 = 当年存进去的 3.6 万 |
| 前几年，钱自己长出来的部分，小得几乎看不见。 | 每根柱子顶上一点点金色 = 当年收益；第 1 年几乎看不见 |
| 但收益会继续产生收益。 | 金色小块下面"长出"更小的金块，像细胞分裂 |
| 按年化百分之六算，大约到第十二年前后，钱一年自己长出来的，第一次超过他一年存进去的。 | 金色部分逐年变高；第 12～13 年金色高度越过灰色，打上标记"自己长的 > 存进去的" |
| 偏偏就在这时候，股市大跌，账户几个月少了二十多万。 | 曲线断崖下跌，数字跳红"-22 万"；音乐抽空，只剩心跳 |
| 这时候，很多人会卖。 | 切到 100 个小人方阵 |
| 一份覆盖四千多万基金投资者的统计里：近一半的人，持有不到三个月就离场，这部分人平均是亏的； | 方阵里 46 个小人变红、退场，旁边标"持有不足 3 个月：平均亏损" |
| 持有超过十年的人很少，不到百分之二，但其中绝大多数都赚了钱。 | 只剩 2 个小人留在原地，变成金色，标"持有超 10 年：98% 盈利" |
| 小林没卖。后面八年，曲线越来越陡： | 回到曲线，从低点回升，越来越陡，火箭出现 |
| 第二十年，一百三十九万。 | "139 万"爆点；下方拆成"本金 72 万 + 收益 67 万" |

## 五、A 股 3000 点（2:20–3:10）

**要讲明白**：①点位只是价格，不含分红；②定投为什么能摊低成本；③长期上涨不代表每一段都上涨。

| 口播 | 动画 |
|---|---|
| 很多人会问：A 股十几年还在三千点，这套在中国行得通吗？ | 弹幕式的问题从屏幕右侧飘过 |
| 先看点位。二零零七年，上证指数到过六千一百多点，现在在三千八百点附近。只看点位，确实没回去。 | 上证走势线：2007 年的高点拉一条水平虚线，今天的位置低于虚线 |
| 但点位只算了"房价"，没算"房租"。 | 一套小房子：房价牌不动，旁边不断掉出"房租"金币 |
| 指数点位不包含分红。把分红加回去，沪深三百从二零零四年到现在，年化大约八个点。 | 沪深 300 图上，价格线之上叠出一条金色"含分红"线，两线之间的面积填满金币 |
| 再看买法。从二零零七年最高点开始，一次性买入，十年后亏了三成多；每月定投，同期赚了三成多。 | 两根柱子：左边"一次性买入 -33%"（红），右边"每月定投 +35%"（金） |
| 原因是：价格低的时候，同样的钱能买到更多份额。 | 价格线下方，每个月放一摞份额：价格高时一小摞，价格低时一大摞；最后画出"平均成本线"，明显低于平均价格 |
| 美国的标普五百也一样：长期年化大约百分之十，但二零零零到二零零九年，十年是负的。 | 标普近百年曲线，2000–2009 那一段高亮成灰色，标"失去的十年" |
| 长期看能涨，不代表每一段都能涨。所以前提是：用的是长期不用的闲钱。 | 字幕卡"前提：长期不用的闲钱" |

## 六、为什么阿杰很常见（3:10–3:25）

**要讲明白**：阿杰的选择很常见，不全是意志力问题，花钱的痛感本身在被降低。

| 口播 | 动画 |
|---|---|
| 那为什么，阿杰这样的选择这么常见？ | 很多个阿杰剪影排成一排 |
| 一个原因是，花钱的痛感正在变小。 | 一条"痛感"刻度，从现金到刷卡到先用后付，一路降低 |
| 麻省理工有个实验：同一场球赛的门票，用信用卡出价的人，平均出价接近用现金的两倍。 | 两只手竞价，现金那边的数字停住，信用卡那边一路涨到接近两倍 |
| 分期、免息、先用后付，都是在把付钱的那一刻，推到以后。 | "免息""先用后付""0 首付"弹窗不断弹出，把付款日期推向时间轴右边 |

| 口播 | 动画 |

| 你更像阿杰，还是小林？评论区聊聊。 | 两个选项按钮 + 免责声明 |
