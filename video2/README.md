## 数据口径
- 小林：每月定投 ¥3,000，年化 6%，20 年。第 5 年 ≈ 20.9 万，第 10 年 ≈ 49.2 万，第 15 年 ≈ 87.2 万，第 20 年 ≈ 138.6 万；本金 72 万，收益 ≈ 66.6 万
- 能生活多久：138.6 万 ÷ 每月 6,000 ≈ 19 年（不计投资收益）
- 车贷：20 万、5 年、年利率约 5%，月供 ≈ ¥3,774
- 金句出自摩根·豪泽尔《金钱心理学》："Spending money to show people how much money you have is the fastest way to have less money."
- 人物为虚构案例，未计通胀与涨薪，仅为科普，不构成投资建议

## 文件与重新生成
| 文件 | 作用 |
|---|---|
| `script.py` | 口播台词（改台词从这里改） |
| `tts.py` | 离线 Kokoro 中文男声合成配音，生成 `timeline.js` 时间轴 |
| `index.html` + `engine.js` | 全部画面（每个动画都挂在台词上，改台词后自动对齐） |
| `render.js` | `events` 导出音效事件；`frames` 逐帧渲染；`shots` 截图检查 |
| `music2.py` | 合成配乐、音效并与配音混音（人声出现时自动压低音乐） |

```bash
npm install
python3 tts.py                        # 需要 sherpa-onnx 与 kokoro-multi-lang-v1_1 模型
node render.js events
python3 music2.py && ffmpeg -i /tmp/claude-0/mix.wav -af loudnorm=I=-14:TP=-1.5 -c:a aac -b:a 192k mix.m4a
node render.js frames 30 4
ffmpeg -framerate 30 -i frames/%05d.jpg -i mix.m4a -c:v libx264 -b:v 2800k -pix_fmt yuv420p -c:a copy -shortest out.mp4
```
浏览器直接打开 `index.html` 可实时预览（空格播放）。
