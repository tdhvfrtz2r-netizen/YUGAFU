# 我的大学宿舍

离校前用 iPhone 激光雷达（3d Scanner App）扫描的宿舍。原始扫描经过清理和修复，做成了可以长期保存的三维模型、4K 图片、一张可打印的 A3 海报和一段 40 秒的短片。

房间实测尺寸：**开间 3.59 m × 进深 5.99 m × 层高 2.97 m**，面积约 21.5 m²。

## 做了哪些处理

原始扫描有 14 万个顶点、23.5 万个三角面和一张 9216×9216 的贴图。主要问题有三个：墙上和天花板上有很多破洞，空中飘着碎片，贴图块的边缘有黑边。

1. **摆正房间**：按墙面和地面自动找出房间的方向，纠正了 0.17° 的倾斜和 0.51° 的偏转。地面放在高度 0，房间中心放在原点，单位是米。
2. **去掉碎片**：删除了 300 块悬空的小碎片（共 0.66 m²）、367 个退化或重复的三角面，以及 15 个陷到地板下面的面。
3. **修贴图接缝**：原贴图只有 48% 的面积有内容，其余是黑色。渲染时，贴图块边缘会把黑色混进来，形成黑边。现在每个贴图块的颜色都向外延伸填满了空白，黑边就消失了。另外做了轻微的锐化和对比度调整，幅度很小，以免偏离照片原貌。
4. **补墙洞**：在四面墙、地面和天花板后面 2 cm 处各加了一层“底墙”。底墙的颜色取自扫描里它周围那片墙面，做了平滑过渡，所以破洞处看到的是相近的墙色，不再是透明的。门洞和窗洞保留着，窗外补了一块明亮的天光。
5. **剖面效果**：所有面都是单面的，从外面看时，离你最近的墙和天花板会自动隐去，像一个打开的房间模型。GLB 和 USDZ 在大多数查看器里都会这样显示；OBJ 格式没有单面这个设定，有些软件会把墙两面都画出来。
6. **保持照片原色**：图片和视频直接显示扫描时拍到的光线和颜色，没有再加一层虚拟灯光。GLB 文件用的是 glTF 的“无光照”材质，效果相同。

没有做的事：没有用 AI 去“想象”补全看不见的家具或细节。模型里每一处细节都来自当时的真实扫描。破洞处只补了颜色相近的墙面，没有编造内容。

## 长期保存建议

- **至少存 3 份，放在 2 种介质上，其中 1 份不在家里**：比如电脑一份、移动硬盘一份、网盘一份。这个文件夹也已经存进了 Git 仓库。
- **原样复制，不要另存为**：图片、视频、模型都不要用软件重新压缩，直接复制整个 `dorm/` 文件夹。
- **格式都是开放标准**：glTF 2.0、OBJ、USDZ、JPEG、MP4 (H.264)，不依赖任何一家公司的软件。将来即使某个 App 不在了，也能打开。
- **每一两年检查一次**：用下面的方法核对校验值，确认文件没有损坏。

### 检查文件是否完好

在 `dorm/` 文件夹里运行：

```
sha256sum -c SHA256SUMS.txt        # macOS 用：shasum -a 256 -c SHA256SUMS.txt
```

每一行都显示 `OK`，就说明文件和当初生成时完全一样。

## 如何复现

所有结果都可以从 `original/Untitled_Scan.usdz` 重新生成，见 `scripts/run_all.sh`。需要 Python 3.13、`bpy==5.2.2`（Blender 的 Python 模块）、`usd-core==26.8`、numpy、scipy、pillow、soundfile、ffmpeg，以及思源宋体 / 黑体（Noto Serif SC / Noto Sans SC）。配乐用的是本仓库 `video2/synth.py` 里的合成器。

| 脚本 | 作用 |
|---|---|
| `extract.py` | 从 USD 文件读出顶点、三角面和 UV |
| `clean.py` | 摆正、清理、拟合墙面和地面 |
| `texture.py` | 修贴图接缝，轻微增强 |
| `build_scene.py` | 在 Blender 里搭场景，生成补洞底墙 |
| `export.py` | 导出 GLB / USDZ / OBJ |
| `stills.py`、`plan_render.py`、`poster.py` | 4K 图片、平面图、海报 |
| `video.py`、`music_dorm.py`、`compose.py` | 短片的镜头、配乐和合成 |
| `make_master.py` | 打包 Blender 工程 |
