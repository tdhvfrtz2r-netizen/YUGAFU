## v4 按导演意见改了什么
导演的意见：不限时长；不必围着那个 B站教程转，要面向大众；内容再丰富；自己配好音效；说得更有深度。

1. **开场换成谁都能参与的小测试**：三样谁都见过的东西（几块钱一杯的奶茶、一两分钟一集的短剧、被乐坛看不上的歌），先盖"土"，再翻过来看它们的另一面（数据）。立场仍是"我也曾经看不懂"：*说实话，我的第一反应也是。我的第一反应，错在哪？* 那个 50 分钟的教程挪到第三层"知识门槛"，当证据之一。
2. **讲得更深**（每一处都标了「观点」或注明出处）：
   - 新增"先说「土」这个字"：我们说一个东西土，常常是在说它便宜、直白、用力、粗糙、满大街都是——这些词围成一个光罩。*「土」说的常常不只是东西，还有一句没说出口的话：这不是给「我们」做的。*
   - 第一层加一段：*「下沉」这个词，是从上往下看的。可要是按人数算，他们才是主流。*
   - 第二层加两样证据：2026 年春节档三四线城市票房占比 53.4%（掏钱的人在哪）；社会学家布尔迪厄的一句话——*品味会给东西分类，也会给做分类的人分类*——所以 *说一个东西「土」，也是在说：我和他们不一样。*
   - 第三层加一个总的解释：行为经济学的《稀缺》——*钱和时间都紧的时候，注意力会被眼前的事占满*——所以 *省钱、省时间、省脑子，本身就是需求*。后面四把锁是这句话的四个例子。
   - 第四层：*等它爬上来，人们会换个词：不说「土」，说「接地气」。东西没怎么变，变的是我们离它的距离。*（和"先说「土」"首尾呼应）
   - 反面：点明 *幸存者偏差*；再加一句 *「土」不是成功的配方，对准处境才是*，免得观众把结论听成"越土越好"。
   - 收尾从"我"换成"我们"：*在自己的本行，我们嫌长教程磨叽、嫌它土；换到理财、健身，我们也要「全网最全、不跳步」。*
3. **数据清单全部用上**：v3 没用的 6.96 亿用户、春节档 53.4%、"约千亿 vs 518.32 亿"都放回来了；"约千亿"那一站加了口径注（2025 年含漫剧，和前面 2024 年的 505 亿不能直接比）。
4. **声音**：31 种音效、一条跟着段落走的原创配乐，详见"声音设计"。

## 比喻系统
- **主比喻：钥匙和锁。** 产品是钥匙，处境是锁。单看钥匙形状很怪；看见它对着的锁，才知道它刚好。
- **光罩 = 我们的"正常"。** 先由"土"的五个词围成（先说「土」）；第一层罩住 18 个人；第四层"土"的东西升进罩里、标签翻成"接地气"。
- **新加的四个画面比喻**：一张票根（谁在掏钱）；一条分拣线（分类的人也被分类）；一个圆＝一个人的注意力（稀缺）；一块翻面的标签（"土"→"接地气"）。
- **贯穿线索**：奶茶（开场的卡片 → 第三层 6.4 万个光点 → 第四层旗舰店 → 反面利润下滑）；短剧（开场 → 第三层碎片时间 → 第四层从保安保洁保姆到一线城市）；歌（开场 → 第二层刀郎 → 第三层"表达"）；长教程（第三层的证据 → 进度条升成楼梯 → 收尾"我们也要不跳步"）。

## 文字规则：事实和观点分开
- 【数据】黑体 + Inter 数字，下面一枚"来源 · 年份"角标。方阵、光点、柱子、票根都按真实数字画；"示意"的地方写明示意。
- 【观点】宋体、暖一点的颜色，每层第一句观点带「观点」标记；引用别人的话带「引述」标记和出处。
- 比喻画面（钥匙、台阶、线团、分拣线、注意力的圆）不代表任何数据；圆里的"房租""加班"是举例。

## 声音设计
- **音效跟画面同一帧**：场景代码里在动作发生的那一帧写一个 `<Cue>`（比如钥匙"咔"、盖章、硬币落盘），`scripts/cues.js` 收集成 `audio/cues.json`，`scripts/sound.py` 按时间合成。改时间线，声音自动跟着走。
- **全部程序合成**：振荡器、滤波噪声、卷积混响，没有用任何录音素材；提示音只是两个正弦音，不像任何品牌的声音。31 种：轻点、弹出、盖章、翻牌、亮出、呼啸、上扬、蓄力、低频落点、钟声、钥匙滑入、锁"咔"、硬币、一串硬币、光点闪烁、人群涌动、数字滚动、方块落定、弹开、声呐、画线、标签翻面、下坠、熄灭、手机提示、光罩、台阶、打孔、传送带、分拣、收藏。
- **原则**：音效是标点，不是背景噪音。字多的地方声音少；重点句 ①② ③ 和片名用"低频落点 + 钟声"，并把配乐压低 5 dB 让出位置。
- **配乐**（100 BPM，D 大调，原创）：开场好奇（轻拨弦）→ 片名前收住 → 先说「土」内省（只有铺底）→ 第一层渐强 → 第二层有一点紧张 → 布尔迪厄那段安静下来 → 刀郎变暖 → 第三层稳定的律动 → 第四层往上走（更亮）→ 反面变暗、鼓停 → 收尾加一段钢琴旋律 → 最后两小节和画面一起淡出。
- **混音**：整体 -16 LUFS（网络视频常用响度），峰值不超过 -2 dBFS。另交两条分轨 `out/music.m4a`、`out/sfx.m4a`，想换自己的配乐时用音效那条即可。
