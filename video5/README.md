## 视觉语言（`src/theme.ts`）
「灯火」：每个人是一盏灯。暖金色 = 大多数人的日常和"土"的东西；冷蓝色 = "你"的屏幕光和光罩（你的"正常"）；粉色 = 短剧；黄铜 = 钥匙和锁。
宋体 = 叙述和观点（作者的声音），黑体 + Inter 数字 = 数据和标签。观点句偏暖色，每层第一句带「观点」标记；数据句下面都有来源角标。

## 渲染
需要 Node 18+、ffmpeg。云端没有显卡，用的是 Playwright 预装的 headless Chromium，经 `scripts/chrome-sw.sh` 走纯 CPU 光栅化。本地渲染时把 `REMOTION_BROWSER` 指向本机的 Chrome，或删掉 `remotion.config.ts` 里那一行，让 Remotion 自己下载浏览器。

```bash
cd video5
npm install
node scripts/glyphs.js                      # 收集片中用到的字，渲染前预加载字体分片
node scripts/stills.js 1440 3600 6300       # 截几帧看看（输出 shots/f<帧号>.jpg 和 shots/sheet.jpg）
node scripts/audit.js                       # 读速自检：每行字够不够读完（几分钟）
npx remotion studio src/index.ts            # 可视化预览、拖时间轴
npx remotion render src/index.ts Main out/video.mp4
bash scripts/check.sh                       # 成片自检：规格、每 4 秒一帧的总览图、亮度跳变
```
4 核 CPU、无显卡，全片约 18 分钟。

## 结构
- `src/timeline.ts`：23 个镜头的小节数。改这里，全片时间线自动重排（各场景里的帧号是相对镜头起点写的，改了小节数要跑一遍 `scripts/audit.js`）
- `src/theme.ts`：配色、字体、字号、缓动、入场节奏
- `src/kit/`：文字（逐字显影、观点标记、来源角标、结论样式）、背景与深度计、画布工具（小人、柔光、透视投影）、弹子锁、图标
- `src/scenes/`：Hook（01–04）、Title（05）、L1（06–08）、L2（09–10）、L3a/L3b/L3c（11–16）、L4（17–18）、L6（19）、L7（20–23）
