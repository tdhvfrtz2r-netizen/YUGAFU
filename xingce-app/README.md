# 行测真题库（手机刷题 App）

把开源题库 [ERRRC/xingcezhenti](https://github.com/ERRRC/xingcezhenti)（2016–2026 年 515 套行测真题，58,890 题次，去重后 27,473 道，含答案和官方解析）做成手机打开就能用的刷题页面。

线上版本（私有链接，只有本人能打开）：https://claude.ai/artifact/Hd6Ydfazd8ht8L67WdTKTh

## 功能

- **每日一练**：每天 20 题，按所选地区近 5 年真卷挑没做过的题
- **历年真卷**：按地区、年份找卷；整卷或分模块 练习 / 背题
- **限时模考**：倒计时、答题卡、交卷估分，各模块正确率和用时，看错题解析
- **专项练习**：按模块、题型出题（可选地区范围、题量、只出没做过的），另有「高频重复题」（被 5 套以上卷子考过的 2,926 道）
- **错题本 / 收藏**：做错自动收入，重做答对自动移出
- **我的学习**：近 14 天做题量和正确率、各模块正确率、最需要补的题型、模考成绩变化
- **十年考情**：每年卷数、国考副省级各模块题量变化、各年模块占比、各模块题型占比和走势、逻辑填空高频成语、常考法律、答案分布、题目重复情况

做题记录存在本机，并同步到 Claude 账号（换设备也在）。

## 重新生成数据

```
git clone --depth 1 https://github.com/ERRRC/xingcezhenti
python3 build.py xingcezhenti dist     # 需要 Pillow（带 WebP 支持）
```

`dist/` 里是 `index.txt`、`t/*.txt`（题目，按 模块×年份 分片）、`i/*.txt`（图片包），和 `app.html` 一起发布。
题库数据不放进这个仓库。题目为网友回忆版，答案和解析版权归原出处，仅供个人学习。
