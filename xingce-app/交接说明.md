# 行测真题库 App · 交接说明

> 给接手的人（或新开的 Claude Code 会话）看的。读完这一份就能接着改。

## 一、这是什么

把开源题库 [ERRRC/xingcezhenti](https://github.com/ERRRC/xingcezhenti)（2016–2026 年 515 套行测真题）做成**手机点开链接就能用的刷题网页 App**。纯前端，没有后端、没有数据库、不用登录。

- 515 套卷，58,890 题次；联考卷各省共用题目，**去重后 27,473 道**，全部带答案，只有 7 道原库没解析
- 图片 39,463 张，收录 39,455 张（缺的 2 张原库本来就没有文件）
- 原仓库 816 MB（其中 `.git` 346 MB、重复题文字、PNG 图片），打包后 92 MB，存成 base64 文本后 122 MB

## 四、怎么重新生成

```bash
# 1. 拿题库（浅克隆，约 5 分钟）
GIT_LFS_SKIP_SMUDGE=1 git clone --depth 1 https://github.com/ERRRC/xingcezhenti ../xingcezhenti

# 2. 打包数据（约 1.5 分钟，多进程转图片）
pip install pillow
python3 xingce-app/build.py ../xingcezhenti /tmp/dist

# 3. 生成公开站点，推送后 GitHub Pages 自动更新
rm -rf docs && sh xingce-app/make_site.sh /tmp/dist docs
git add docs xingce-app && git commit -m "..." && git push

# 本地预览（要支持 Range 请求的服务器，python http.server 也能用，只是不支持 Range 会走整包下载）
npx http-server docs -p 8080   # 然后浏览器开 http://localhost:8080
```

**只改了 app.html 时**：不用重跑 build.py，直接 `rm -rf docs && sh xingce-app/make_site.sh <上次的dist> docs`。如果手边没有 dist，把 `docs/` 里的 `index.txt t/ i/` 当 dist 用也行（`make_site.sh` 只从 dist 拷这三样）。

## 五、数据格式（build.py 输出）

托管平台（claude.ai artifact）只收文本类型，所以**所有数据都是 base64 文本**。GitHub Pages 其实能放二进制，但为了两边共用一套，统一用 .txt。

- `index.txt` = base64(gzip(JSON))，启动时加载，约 300 KB：
  - `papers[pid]`：`{t 全名, n 短名, r 地区, y 年份, mods:[[模块号, 起始下标, 题数]], q:[qid...], lim 限时分钟}`，pid = md5(试卷全名) 前 8 位
  - `regions`：`[{r 地区, ps:[pid...]}]`，按 国考→各省→深圳/广州市考→选调 排
  - `qm[qid]` = `[分片号, 模块号, 题型序号, 首次出现年份, 被几套卷使用]` —— 专项练习、统计都靠它，不用加载题目
  - `tyn[模块号]`：题型名列表（来自原库标注，如 图形推理/逻辑填空/增长）
  - `hot`：被 ≥5 套卷使用的 qid（2,926 道，「高频重复题」）
  - `stats`：十年考情的预计算统计（每年卷数、国考副省级各模块题量、模块占比、题型分布和逐年数量、ABCD 答案分布、逻辑填空高频成语/双字词/关联词、法律常识高频法律、重复次数分布）
  - `nI`：图片包个数
- `t/<n>.txt` = base64(gzip(JSON))，**按「模块 × 首次出现年份」分片**，共 66 片，每片 20–750 KB：
  - `q[qid]` = `{m 模块, ty 题型, s 题干HTML, k 选项字母如"ABCD", o 选项HTML数组(纯图片选项时省略), a 答案如"B"或"AC", at 文字答案(无选项题), x 材料id, e 解析HTML}`
  - `x[材料id]` = 材料 HTML（资料分析的材料、言语的共用文段）
  - `im[图片key]` = `[包号, 字符偏移, 字符长度, 宽, 高]`
- `i/<n>.txt`：图片包，每包 ≤1.2 MB。**每张图单独 base64 后首尾相接**，所以可以用 HTTP Range 只取一张的那几个字符再解码
- HTML 里的图片写成 `<img data-i="t:文件名">`（题目图）或 `data-i="f:文件名" class="fx"`（解析里的公式图），前端加载后换成 blob URL
- 图片转码：题目图取「无损 WebP」和「有损 q88」中较小的（无损不超过有损 1.5 倍就用无损），透明底铺白；公式图无损、保留透明（深色模式下 CSS 反色）

build.py 还做了：HTML 白名单清洗（去 script/style/事件属性）、去掉解析里的「故正确答案为X」、材料归属推断（资料分析管到下一份材料；其他模块最多 5 题、题号相差 ≤30、不是逻辑填空）、试卷短名（`nick()`）、模考限时估算。

## 六、App 结构（app.html）

纯原生 JS，无框架，只从 cdnjs 加载 `pako`（浏览器不支持 DecompressionStream 时解 gzip 用）。

**页面路由**：页面内栈 `STACK`，`nav(path)` / `back()` / `replace(path)`，不用地址栏 hash（claude.ai artifact 里 hash 路由不可靠）。元素上写 `data-go="paper/xxx"` 就能跳转。

| 路径 | 函数 | 内容 |
|---|---|---|
| `home` | `home()` | 首次选地区；今日做题/正确率/连续天数；每日一练；继续上次；六宫格入口；添加到桌面提示 |
| `pick` | `pickRegionPage()` | 改考试地区 |
| `bank/paper`、`bank/topic` | `bank()` | 题库：历年真卷（地区宫格）/ 专项练习（六模块） |
| `region/<地区>` | `regionPage()` | 该地区按年份列卷，带进度 |
| `paper/<pid>` | `paperPage()` | 限时模考 / 整卷练习 / 整卷背题 / 按模块 练·背 |
| `topic/<模块号>` | `topicPage()` | 题型列表 → `topicSetup()` 弹层选范围/题量/顺序/方式 |
| `do` | `startSes()` → `renderQ()` | 做题页（练习、背题、模考、模考回看四种模式） |
| `report/<pid>` | `reportPage()` | 模考成绩：估分、各模块正确率和用时、看错题解析、重考 |
| `wrong/wrong`、`wrong/star` | `wrongPage()` | 错题本 / 收藏，按模块重做或背 |
| `ana/me`、`ana/stats` | `anaPage()` → `meHTML()` / `statsHTML()` | 我的学习分析 / 十年考情 |
| `set` | `settings()` | 字号、答对自动下一题、离线下载、清空记录、关于 |

**做题会话 `SES`**：`{sp 来源描述, qids, i 当前题, mode, picked{qid:答案}, sel 多选暂存, ex 模考记录}`。`sp.k` 取值：`paper` `exam` `review` `topic` `daily` `wrong` `star`。`ensure(qids)` 先加载需要的分片，`hydrate(el)` 把图片填上（优先 Range 取单张，不支持就整包取并缓存，并校验结果是 WebP）。

**每日一练**：所选地区近 5 年真卷里没做过的题，按 政治2 常识3 言语5 数量2 判断5 资料3 共 20 题，用日期做随机种子，当天固定。

**模考估分**：按模块权重（政治 0.7、常识 0.6、言语 0.8、数量 0.9、判断 0.7、资料 1.0）折算百分制。计时只在页面可见时走（`ex.used` 累加秒数），离开页面暂停。

## 七、做题记录（状态 `S`）

存在 `localStorage['xc-v2']`，结构：

```js
{
  region, fs 字号, autoNext,
  rec: [16个桶]  // rec[qid%16][qid] = [最近对错0/1, 做过次数, 错过次数, 时间(分钟戳)]
  wrong: [4个桶], star: [4个桶]   // [qid%4][qid] = 加入时间
  rv: [4个桶]     // [qid%4][qid] = [复习阶段0/1, 到期日 YYYYMMDD]，错题复习用
  ex: {pid: {a:{题下标:答案}, tt:{题下标:秒}, used 已用秒, done, i, res 成绩, prev 上次成绩}},
  hist: [[时间, pid, 估分, 答对, 题数, 用时秒]] // 最多 200 条
  day: {'YYYY-MM-DD': [做题数, 答对数, 秒]},
  daily: {d 日期, r 地区, q:[qid]},
  last: {spec, i, label}, // 继续上次
  _ut: {桶名: 更新时间}
}
```

- **错题复习**（`review()`）：做错 → 进错题本，1 天后到期；到期答对 → 阶段 1，3 天后再到期；阶段 1 到期再答对 → 移出。没到期时答对不改进度；没有 rv 记录的旧错题当作已到期。错题本页顶部是「今天该复习 N 道」
- **一组做完的小结**（`finish()`）：各模块对几道、平均用时对比建议用时（`SUG`）、最慢的一题。练习里每题用时存在 `SES.tt`，只在本次会话里，不存盘
- 微信内置浏览器打开时弹一次提示，让用户换浏览器打开（微信会清本地数据）
- 记录以 **qid** 为键：同一道题在多套卷里出现，做一次处处都算做过
- 分桶是为了同步：私有版里 `sync` 对象把每个桶写成 artifact db 的一个文档 `data/users/<uid>/<桶名>`（单文档上限 256 KB），按 `_ut` 时间戳 后写覆盖。公开版没有 `window.claude`，`sync` 自动不启用
- 离线：`sw.js` 缓存优先 `t/ i/`，页面和 index 网络优先；Range 请求在 SW 里改成取整包缓存。设置页「下载全部题库」并发 3 个下载全部 196 个文件

## 八、已测过的

用 Playwright（Chromium，390×844 手机尺寸）跑过完整流程：选地区 → 每日一练答题 → 整卷练习（资料分析材料+表格图片）→ 背题（图形推理）→ 模考答题卡交卷 → 成绩页 → 错题解析 → 分析两页 → 专项 → 错题本；Range 和非 Range 两种服务器都测过；离线下载 196 个文件后断网能做题。无报错、无横向溢出。

**没测过的**：真 iPhone / 安卓手机、微信内置浏览器、GitHub Pages 线上实际速度和 Range 支持情况（开发环境访问不了 github.io）、私有版的账号同步。

## 十、踩过的坑

- **claude.ai artifact 限制**：只收标准文本/图片等类型（`.bin` 会被拒）；每版本最多 511 个文件、256 MB；单次发布最多 255 个文件、64 MB（所以分了三次上传）；没有 service worker；`alert/confirm` 不可用（确认框都做成页面内弹层）；只能从 cdnjs 等少数 CDN 加载脚本
- **全局变量别叫 `top`**（和 `window.top` 冲突，脚本直接报错），所以页头函数叫 `hdr()`
- 自己的 CSS 里要有 `[hidden]{display:none!important}`，不然 `#sheet{display:flex}` 盖掉 hidden，透明遮罩挡住所有点击
- `.top h1` 不要加 `text-wrap: balance`，会让 nowrap 失效、标题换行
- 原库 `90-图片/公式图` 约 28px 高（2 倍图），按 `高/28×1.3em` 显示才和正文一样大
- 更新私有版：claude.ai 里用 Artifact 工具发布同一个 `app.html`，数据文件已在线上不用重传（除非重跑了 build.py，分片号会变，要全部重传）
